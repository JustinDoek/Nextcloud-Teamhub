Mission of Teamhub
Core Mission
Teamhub is a Nextcloud app that serves as an integration, automation and presentation layer for team-based work in a Nextcloud environment.
Scope
Teamhub develops a team-based view with its own features like widgets, links, and a message stream; integrations with standard apps (Calendar, Files, Deck, Talk); and an open integration layer via API endpoints that allows other apps to add widgets or secure iframes
Target Audience

Teams and organizations using Nextcloud for collaboration
App developers who want to hook into Teamhub views with their own widgets linking to their app, mini-apps, or iframes

Core Features

Team-based views with configurable widgets, links, and message stream
Integrations with Nextcloud Teams, Calendar, Files, Deck, Talk and Intravox
Open API endpoints for external apps to register and publish widgets
Admin settings for standard permissions and configurations

Differentiators

Focus on team-specific views (not personal like Dashboard)
Open integration layer with rich APIs for developer extensions
Admin settings for organization-specific rollout and standardization
